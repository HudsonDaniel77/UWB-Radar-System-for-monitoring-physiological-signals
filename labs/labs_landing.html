# Industrial Toolbox Labs mmWave Labs are source code examples on how to get started with the mmWave Sensors. Each lab provides detailed instructions to follow along while experimenting. Source code of each lab can be loaded directly into Code Composer Studio through the integrated view in TI Resource Explorer. # Lab Summary | Lab Name | Description | |-------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------| | [Area_Scanner](./Area_Scanner/docs/area_scanner_users_guide.html) | using range, velocity, and angle data from a TI mmWave sensor, detect objects or people as they enter or exit configurable zones of interest | | [Automated_Doors_And_Gates](./Automated_Doors_And_Gates/docs/automated_doors_user_guide.html) | use tracking algorithms to sense range, speed, and direction of motion used to trigger the opening of a door | | [Fundamentals](./Fundamentals/fundamentals_landing.html) | a collection of small modifications that can be applied to other labs such as [Hard Coded Configuration](./Fundamentals/Hard_Coded_Config/docs/hard_coded_config_user_guide.html), [Low Power Configuration](./Fundamentals/Low_Power_Demo/docs/68xx_low_power_demo_user_guide.html), and [Software CLI Reset](./Fundamentals/Soft_Reset_Using_CLI/docs/soft_reset_using_cli_user_guide.html) | | [Gesture_Recognition](./Gesture_Recognition/gesture_landing.html) | two different implementations of gesture recognition and classification using machine-learning techniques, [Gesture and Presence Detection](./Gesture_Recognition/Gesture_and_Presence_Detection_64xx/docs/gesture_and_presence_detection_64xx_users_guide.html) and [Multi Gesture and Motion Detection](./Gesture_Recognition/Multi_Gesture_and_Motion_Detection_68xx/docs/multi_gesture_and_motion_detection_68xx_user_guide.html) | | [Level_Sensing](./Level_Sensing/docs/high_accuracy_user_guide.html) | obtain millimeter-level accuracy on range measurements with a TI mmWave sensor | | [Long_Range_People_Detection](./Long_Range_People_Detection/docs/long_range_people_detection_user_guide.html) | use a TI mmWave sensor to count and track multiple people simultaneously up to 100m away | | **[Out_Of_Box_Demo*](./Out_Of_Box_Demo/docs/Out_Of_Box_Demo_User_Guide.html)** | **get started sensing and visualizing with a TI mmWave device** | | [Parking_Garage_Sensor](./Parking_Garage_Sensor/docs/parking_garage_sensor_68xx_users_guide.html) | use range, velocity, and angle data from mmWave sensors can enable the detection of parked or stationary cars as they enter or exit zones of interest | | **[People_Counting*](./People_Counting/people_counting_landing.html)** | **a collection of labs that leverage the GTRACK algorithm to localize people and track their movement across a scene** such as [3D People Counting](./People_Counting/3D_People_Counting/docs/3d_people_counting_user_guide.html) and [Overhead People Counting](./People_Counting/overhead_3d_people_counting/docs/overhead_3d_people_counting_user_guide.html) | | [Robotics](./Robotics/robotics_landing.html) | a collection of ROS powered robotics and factory automation use cases such as [Mobile Tracker](./Robotics/Mobile_Tracker/docs/Mobile_Tracker_User_Guide.html), [Safety Bubble](./Robotics/autonomous_robotics_ros/docs/safety_bubble/Safety_Bubble_with_ROS_for_mmWave_user_guide.html), [Sense and Avoid](./Robotics/autonomous_robotics_ros/docs/sense_and_avoid/Autonomous_Robotics_with_ROS_for_mmWave_user_guide.html), [ROS Driver](./Robotics/ros_driver/docs/TI_mmWave_ROS_Driver_Users_Guide.html), and [Small Obstacle Detection](./Robotics/Small_Obstacle_Detection/docs/small_obstacle_detection_user_guide.html) | | [Traffic_Monitoring](./Traffic_Monitoring/docs/traffic_monitoring_users_guide.html) | use a TI mmWave radar for robust, long-range sensing in traffic monitoring and other applications | | [Vital_Signs](./Vital_Signs/vitalSigns_landing.html) | use TI mmWave radar to detect miniscule motions like displacement of the chest when the heart beats or a person breathes, [Vital Signs with People Tracking](./Vital_Signs/Vital_Signs_With_People_Tracking/docs/vital_signs_with_people_tracking_user_guide.html) also leverages people tracking for improved robustness | **(\*) Out_Of_Box_Demo** and **People_Counting** are considered foundational labs because other labs build on them: * **Out_Of_Box_Demo** is the most basic application where a standard configuration is used to sense and process a generic scene. The processed data can be visualized immediately using the *mmWave Demo Visualizer* web tool so that a beginner can quickly gain a sense of intuition into using a radar device. * **People_Counting** establishes the use of the GTRACK tracker algorithm. Many advanced radar applications are built on top of the tracker algorithm. # Lab Compatibility | Application | Lab Name | IWR1443 | IWR1642 | IWR1843 | IWR6843ISK | IWR6843ISK-ODS | IWR6843AOP |
